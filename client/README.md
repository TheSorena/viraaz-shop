# Viraaz Client

## Development

```bash
npm install
npm run dev
```

The dev server runs on http://localhost:5173 and proxies `/api` requests to the backend (see `vite.config.js`).

## Build

```bash
npm run build
```

Static files are output to `dist/`. Serve them with any static file server, or let the Express backend serve them in production (see README at project root).
